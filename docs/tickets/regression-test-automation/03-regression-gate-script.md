# 03 — 回归闸门脚本（静态层 + 零 LLM 组合层）

**What to build:** 一条命令跑完确定性回归，退出码可判、报告可归档。闸门按「能确定就不烧额度」组织：静态层（类型检查、既有单测、测试清单一致性）与零 LLM 组合层（组合配置导出 + 逐 loader id 递归计数 = 1、零 LLM 组合冒烟的工具集合与首轮锚定、降级路径冒烟、seeded 预览探针、部署位生产文件 sha 比对、宿主版本与会话格式版本比对、依赖树农场代比对、组合中不出现假模型的遏制断言）。退出码三态：全过、任一断言失败、环境前置不满足。防护要点：默认运行一个**自持的闸门组合**（不依赖任何相邻仓库，因此任意 checkout 与 CI 可跑）；全程写临时 home，真实用户目录零写入；持仓库本地锁串行化并发运行。

**Blocked by:** 01 — 路径可移植性与宿主依赖解析；02 — 版本清单与基线资产入库

**Status:** done — 2026-09-11（实现与验收证据齐；未提交，证据见 evidence/03-regression-gate.md）

**施工图:** `docs/regression-test-automation-plan.md` §2.2、§4.4、§5.1、§5.2、§5.4；用户决策 Q2（隔离）、Q12（报告 schema）、Q13（反劫持）、Q16（缺席/陈旧分离）、Q20ii（串行锁）。

- [x] 单一入口脚本可跑静态层与零 LLM 组合层，全绿时退出码 0
- [x] 人为破坏任一断言时退出码 1；宿主版本或会话格式与清单不符时退出码 2 并提示重采基线
- [x] 组合层断言：配置导出退出码 0 且**逐 loader id 递归计数为一**（导出本身不检测重复，必须单独断言）
- [x] 组合层断言：零 LLM 冒烟的工具集合与首轮锚定符合期望；降级路径冒烟通过；seeded 预览探针全绿（含其红线断言仍在）
- [x] 部署位一致性成为前置断言，且「陈旧」与「缺席」分别表达；两者默认拒绝，各自可显式豁免
- [x] 任何豁免都写入报告并在终端打印醒目警告；豁免不改变其余断言的结果
- [x] 结构化报告落仓库实验目录约定下并带日期，含：闸门版本、起止时间、git HEAD 与是否脏、宿主版本、会话格式版本、组合模式、部署位比对结果、逐层逐条断言（状态 + 证据 + 明细）、豁免数组、汇总计数
- [x] 闸门断言组合导出中不出现假模型的 provider 名或模块路径
- [x] 闸门断言依赖树解析到的宿主版本等于清单记录；持锁运行避免并发污染
- [x] 全程真实用户目录零写入（含 profile 规范化回写）；报告记录副本侧被回写文件的 sha
- [x] 闸门不自动同步部署位；同步仍是显式动作（脚本内不存在同步调用）
