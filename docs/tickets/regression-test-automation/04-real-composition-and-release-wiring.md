# 04 — 真实组合模式与发版接线

**What to build:** 让闸门能在**真实开发组合**下做交付前验证，而不必修改用户环境、也不必把另外两个仓库变成硬依赖。做法是运行期渲染：读取真实开发 profile 的补丁文本，按环境变量替换其中的仓库根路径（本仓库、相邻两个仓库；默认取相邻 checkout），物化到隔离临时 home，连同设置副本与会话根一起使用；源 profile 只读。报告同时记录源 profile 的 sha 与渲染后的 sha，使「验的是哪份组合」可追溯。`real` 模式缺少相邻仓库时明确报环境错误而非静默降级。同时把闸门接进发版流程：打包前调用真实组合模式，且**永不带任何豁免参数**。
