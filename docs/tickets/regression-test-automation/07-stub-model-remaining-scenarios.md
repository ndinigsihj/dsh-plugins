# 07 — 假模型行为层其余场景

**What to build:** 在已跑通的假模型层上补齐其余回归场景，使本轮踩过的坑逐条被锁定：bash 提升后在沙箱中的可见性与压缩后回退、会话恢复后请求头中路由发现工具的在场、委派策略的两条规则（省略路由时继承父路由、集合外路由被拒绝）。全部零额度、确定性、断言只落在会话事件上。

**Blocked by:** 06 — 假模型行为层骨架 + 首条回归红绿（12-2）

**Status:** ready-for-agent

**施工图:** `docs/regression-test-automation-plan.md` §3.1「首批场景」、§5.4；用户决策 D2（手写脚本）。

- [ ] 场景：bash 提升后沙箱可见，压缩后回退为持久 shell（两条断言均可独立失败）
- [ ] 场景：会话恢复后首个请求头包含路由发现工具（对应按用途选择模型的能力面）
- [ ] 场景：委派省略路由时继承父路由（断言子会话记录的路由等于父会话）
- [ ] 场景：委派指定集合外路由时被拒绝（断言不会发出该路由的请求）
- [ ] 每个场景头部注明锁定的不变量与来源；失败信息能直接指向违反的不变量
- [ ] 全部场景接入闸门的确定性分层，整层可一条命令运行且全绿
- [ ] 任一场景被注入反向断言（人为破坏）时该层退出码非零（抽验至少一个场景）
