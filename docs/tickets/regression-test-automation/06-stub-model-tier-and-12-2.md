# 06 — 假模型行为层骨架 + 首条回归红绿（12-2）

**What to build:** 补上最大的一块覆盖缺口——在没有额度、没有网络的条件下跑**真实 agent loop**。做法是在进程内组合（载入宿主 profile 的 bundle 层 + 补丁覆盖层）里，用宿主既有的适配器注册接口注入一个**脚本化回放适配器**（只需实现流式方法，其余方法有默认实现），然后按既有 driver 范式创建 agent、挂载目标组合、发用户消息、等待空闲，再只读会话事件断言。脚本以「轮次 → 分块序列」表达，工具调用参数为原始 JSON 字符串，分块顺序照生产适配器的收尾形状。本票交付机制本身 + 第一条真实回归的场景：首轮 bash 调用缺少描述参数（本轮实测的时序类回归），要求它**先红后绿**并留档，证明闸门拦得住这条回归而不是碰巧通过。遏制规则：假模型只出现在补丁覆盖层，使用独立 provider 名，不进入组合行与部署位。
