# 02 — 前置取证：目标版本实测事实

**What to build:** 在临时前缀（独立缓存，不碰真实安装、Profile 与部署位）安装目标版本，取得并落档六项事实：① 异步替代接口的确切签名；② 是否真有面向用户的批量迁移工具及其命令形态；③ 新宿主对旧格式会话的读写行为（只读不改写 vs 打开即改写）；④ 旧目录形态 Preset 是否仍被加载；⑤ 无文档版本的包树差异；⑥ 旧版本包是否仍可从仓库重取。另明确附件与 storages 是否属于会话恢复面。结论写回计划的未验证清单，作为后续票的施工依据。
