## 4. 结论

- **rc.3 的实际变更面 = 依赖钉版（可复现构建），无代码差异**（就 CLI 包与 dsh-base 这两个可逐文件比对的产物而言）。
  这与"无 release notes"的观感一致：它是把浮动依赖钉回已测版本的 republish。
- **事实⑥：0.1.5-rc.2 仍可从 registry 重取**（`npm pack` 实测下载成功、shasum 与元数据一致；
  也可 `npm i -g @deepseek-ai/dsh@0.1.5-rc.2`，解析成功）。
  但重取的是**混合树**（rc.2 CLI + rc.3 子包），不等于当前本机旧安装的原样副本。
- 因此计划 §7 第 2 步"本地留一份旧版本包副本"仍是唯一能精确还原旧树的路径；
  回滚**不依赖** registry 上 rc.2 是否仍在（当前在，但已不可逐字节复现原树）。
- 目标版本锁定不变：`0.1.7-rc.1`；正式版未发布（`latest` 仍是 0.1.5-rc.3，属无文档 republish）。
