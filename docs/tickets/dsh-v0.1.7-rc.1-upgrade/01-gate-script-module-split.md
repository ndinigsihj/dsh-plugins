# 01 — Prefactor：组合闸门脚本拆模块

**What to build:** 把组合闸门脚本按职责拆成模块（报告、断言、组合导出解析、部署位校验、宿主钉版与会话格式断言、隔离快照、假模型驱动入口各自成模块），对外行为零变化：既有分层命令、退出码、豁免语义、报告结构与字段名逐字不变。为后续"按 Profile 维度重建工具面期望"的改动提供落点（"先让改动变简单，再做简单改动"）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**施工图:** `docs/dsh-v0.1.7-rc.1-upgrade-spec.md`（Testing Decisions：组合与闸门 seam）；结构欠账记录见上一轮收口证据

- [ ] 拆分后 `tsc --noEmit` 与 `npm test` 全绿，用例数不减少
- [ ] 既有闸门分层命令逐层跑通，退出码与两种豁免语义不变（各自红/绿路径实测）
- [ ] 同一输入下报告结构与字段名与拆分前逐字一致
- [ ] 拆出的文件与函数满足仓库硬标准（单文件 <300 行、单函数 <50 行）
- [ ] 无行为变更：不新增断言、不改判据、不动部署位与真实用户目录

**范围外（本票不做）:** 新增闸门能力（Profile 维度期望、宿主换代等）；报告格式重设计；修复既有判断项。
